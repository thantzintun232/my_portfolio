# Rules for this repo
- Work only inside this folder.
- Never invent facts. FACTS.md is the only source for skills, projects, employers,
  dates, numbers and certifications. If something is missing, write "TODO: confirm"
  on the page and list it in your final report.
- Keep the existing design, layout and navigation unless a change is needed.
- Do not install global packages or add dependencies. Prefer a dependency-free script.
- Do not run git commit, push, reset or delete files. Do not touch .git.
- Show your plan before editing. Ask before doing anything not in the plan.
- Final report: files changed, checks run and results, what you could NOT verify,
  and judgement calls I should review.
