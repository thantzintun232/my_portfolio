# Rules for this repo
- Work only inside this folder.
- Never invent facts. FACTS.md is the only source for references. If something is missing, write "TO BE CONFIRMED" with red colour on the page and list it in your final report.
- Keep the existing design, layout and navigation unless a change is needed.
- Do not install any other dependencies.
- Do not run git commit, push, reset or delete files. Do not touch .git.
- Add a small check script to run the tests points 
- Show your plan before editing. Ask before doing anything not in the plan.
- Final report must include files changed, results, and everthing need to be confirmed.
